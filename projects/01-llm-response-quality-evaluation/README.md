# Project 01: LLM Response Quality Evaluation

## Objective
Evaluate and compare responses generated by two
large language models using a structured rubric.

## Models
- Claude Haiku 4.5
- Gemini 3 Flash

## Evaluation Dimensions
1. Accuracy
2. Relevance
3. Completeness
4. Clarity
5. Instruction Following

## Methodology
Both models will receive identical prompts.
Their responses will be independently evaluated
using a consistent 1–5 scoring scale.

## Dataset
Target: 30 prompts and 60 model responses.

## Current Status
In Progress

## Final Deliverables
- Evaluation dataset
- Comparative analysis
- Evaluation report
